# Rishabh Bohra’s portfolio

[Live portfolio](https://sudo-mystic.github.io/portfolio/)

Project descriptions, links and case study text live in `source/projects.py`. The shared page layout and page-specific content live in `build.py`.

Run `python3 build.py` after editing the source and commit the generated HTML and sitemap alongside it. Use `python3 build.py --check` to check that the published files match the source. No Python packages are required.

GitHub Pages serves the committed files from `main`. To preview the main pages locally, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/`.
